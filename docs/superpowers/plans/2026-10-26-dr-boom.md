# Dr. Boom implementation plan

**Goal:** Build the requested playable Bomberman-inspired game in the current directory.
**Architecture:** Native Canvas rendering, deferred scripts, ES6 entity classes, integer grid coordinates, and a requestAnimationFrame loop with delta time. GameMap owns tile data; Game owns simulation and entity collections; main owns DOM input and UI wiring.
**Tech stack:** HTML, CSS, vanilla JavaScript; Node built-ins for development tests only.
**Spec:** The user's requirements and seven execution steps in this conversation.

## Constraints and decisions

- 15 columns, 13 rows, 40px tiles; 0 empty, 1 wall, 2 destructible.
- No external images, fonts, libraries, engines, or build step.
- Work directly in the requested directory; leave changes uncommitted for review.
- Use grid-based collision, with short visual interpolation between logical cells.
- Two active bombs, a 2.4s fuse, two-tile blast range, three enemies, and a three-minute round.
- Support keyboard and on-screen controls, pause on focus loss, and restart.
- Ruling: execute immediately using the supplied specification; the user explicitly requested creation now.

## Steps

- [x] 1. Create index.html and style.css: centered responsive canvas, HUD, controls, and accessible overlays.
- [x] 2. Write meaningful core behavior tests and observe failures before implementation.
- [x] 3. Create Constants.js, Player.js, Bomb.js, Enemy.js, and Explosion.js.
- [x] 4. Create Map.js: deterministic layout, collision queries, blast ray calculation, and native drawing.
- [x] 5. Create Game.js: simulation, collision, bomb placement and chain reactions, win/loss, pause, restart, and rendering.
- [x] 6. Create main.js: DOMContentLoaded initialization, input, animation frame loop startup, and UI actions.
- [x] 7. Run Node behavior tests and JavaScript syntax checks; inspect desktop and mobile in a real browser if available; perform a fresh code review.

## Review focus

- Blasts stop at walls and the first crate, including during chain reactions.
- A player can leave a planted bomb but cannot reenter it.
- Contact, active flames, and timeout end a round; killing the last enemy wins only if the player survives.
- Pausing and switching tabs freeze timers and clear held inputs.
- Restart clears bombs, fire, score, timers, and input without creating duplicate animation loops.

## Verification

Run `node --test tests/game.test.cjs`; tests use real game classes with a minimal Canvas stub.
Run `node --check` for each JavaScript file. Use Chrome headless with its native debugging protocol for browser smoke tests if available; no project dependency is needed.
